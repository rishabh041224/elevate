Elevate Technology website
==========================
1. Unzip this folder.
2. Double-click index.html to open the site in Chrome, Edge or Safari (internet needed for fonts and 3D libraries).
3. To publish: upload index.html to any web host (Netlify, Vercel, GitHub Pages, cPanel public_html).

Edit these near the top of the script in index.html (search for the names):
- WA_NUMBER        your WhatsApp number with country code, digits only, e.g. 919876543210
- INSTAGRAM_URL    your Instagram page
- FACEBOOK_URL     your Facebook page
- GEMINI_API_KEY   optional Google Gemini key for the AI chat (or set GEMINI_PROXY_URL to your own server)

Replace the sample content: stats, case-study results, email address and office hours.
